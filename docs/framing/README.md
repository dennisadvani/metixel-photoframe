# Metixel Adaptive Framing Engine — Documentation

This folder documents the **Metixel Adaptive Framing Engine**: a pure
geometry/logic library that computes frame, mat, mat window, whitespace and
artwork geometry for a digital display.

| Document | Contents |
| --- | --- |
| [Overview & repository guide](./README.md) | What the engine is, files, quick start. |
| [**Geometry Model**](./geometry-model.md) | **Canonical specification.** Frame/mat/window/whitespace/ambient model, units, branches, ring proportions, invariants. |
| [Usage / API](./usage.md) | Input/output dataclasses, units, and how to call the engine. |
| [Testing](./testing.md) | The scenario matrix and how to run/extend the test suite. |
| [Visualization](./visualization.md) | Rendering framing scenarios to images. |

> **`docs/geometry-model.md` is the specification.** Where the document and the
> code disagree, the document wins.
