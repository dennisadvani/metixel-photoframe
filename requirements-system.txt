# System packages required by Metixel Photoframe.
# The OTA updater installs any missing packages from this list before
# the pip install step.  Already-installed packages are skipped.
# New releases may add to this list — the updater handles it idempotently.
# This list is the single source of truth for system packages; it is applied
# by scripts/ota_install.sh on every install and upgrade.

# Python runtime
python3-pip
python3-pil
python3-numpy
python3-libcamera
libopenblas0

# Display / graphics stack
# cage is the Wayland compositor; Qt runs as its client with
# QT_QPA_PLATFORM=wayland pinned in metixel-cage.service.
cage
wlr-randr
# grim captures the composited output via wlr-screencopy (the dashboard's
# Take Screenshot button).  It is a Wayland client of cage, driven by the
# backend with the same minimal env wlr-randr already uses — see
# metixel/display/screenshot.py.
grim
seatd
# xwayland is retained for now. Nothing at runtime needs an X server any more —
# mpv embeds via the libmpv render API and Qt uses the Wayland plugin — but it
# is only removed once Wayland-native rendering is proven on hardware, because a
# missing runtime package is unrecoverable on a wall-mounted frame.
xwayland

# Qt + mpv.  These MUST come from apt: the pip PySide6 wheel omits the GBM eglfs
# plugin, and `ota_install.sh` uses --ignore-installed so a pip copy would shadow
# the apt one under ~/.local and break the platform plugin lookup.
# libqt6waylandclient6 provides the `wayland` QPA plugin that
# QT_QPA_PLATFORM=wayland resolves to; without it Qt aborts on startup, which is
# the intended loud failure rather than a silent xcb fallback.
python3-pyside6.qtcore
python3-pyside6.qtgui
python3-pyside6.qtwidgets
python3-pyside6.qtopenglwidgets
libqt6waylandclient6
python3-mpv
mpv
libmpv2

# Qt Quick + Qt Multimedia — the GPU-composited renderer (Frame.qml + QmlBackend).
# Measured on a Pi 5 against the software path it replaces, on the same 60 fps
# production-format clip: 59.91 fps presented / 99.72% of frames vsync-locked for
# 35.5% of one core, versus 182% for the libmpv software renderer.  These are the
# packages that make smooth playback possible, so a missing one is a performance
# regression that looks like a rendering bug.
#   qtquick + qml   - the scene graph and its QML engine
#   qtmultimedia    - QMediaPlayer + VideoOutput.  Hardware-decodes HEVC on a Pi 5
#                     through V4L2 stateless (/dev/video19, DMABuf in and out).
#                     Note a Pi 5 has NO H.264 hardware decoder at all, which is
#                     why the pipeline re-encodes to a per-board codec profile.
#   qml6-module-*   - the QML modules Frame.qml imports: qtquick for the items
#                     themselves, qtquick-shapes for ShapePath (the mat ring).
#                     qtquick-effects is installed for MultiEffect but is
#                     deliberately NOT used for blur — production blurs offline in
#                     ambient_blur.py and blits a pre-blurred JPEG.
#   libqt6quick6 / libqt6multimedia6 - the native libraries behind them.
python3-pyside6.qtquick
python3-pyside6.qml
python3-pyside6.qtmultimedia
qml6-module-qtquick
qml6-module-qtquick-shapes
qml6-module-qtquick-effects
libqt6quick6
libqt6multimedia6

# Media processing
ffmpeg
cpulimit

# Input / CEC / DDC
# libcec-dev + cec-utils provide the native libcec library. The Python
# bindings come from the PyPI 'cec' package (python-cec) — see
# requirements-pip.txt. The Debian 'python3-libcec' package does NOT exist in
# Trixie and exposes a different API, so it is NOT listed here.
cec-utils
libcec-dev
python3-evdev
# ddcutil talks DDC/CI over I²C (monitor brightness/contrast/input, etc.)
ddcutil
# i2c-tools provides the i2c-dev kernel module + i2cset/i2cget used by ddcutil
# to talk to the monitor over the I²C bus.
i2c-tools

# Networking
git
samba
iptables-persistent
hostapd
dnsmasq
